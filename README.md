## About me

I'm a final-year **Informatics Engineering student at ISEP** (graduating 2027), focused on **networking and infrastructure**: routing and switching, enterprise networks, virtualization and the systems underneath applications. I'm **CCNA certified** and I'm studying towards CCNP Enterprise.

I also work with **AWS and cloud architecture**. I finished **1st in Portugal at AWS Community GameDay Europe 2026** as part of a team, I build serverless projects with Terraform, and I write about cloud on AWS Builder Center.

## What I enjoy

- **Enterprise networking**: routing, switching, redundancy, segmentation and troubleshooting on real Cisco hardware.
- **Infrastructure and automation**: Linux, Ansible and Terraform to make environments reproducible.
- **Cloud and solutions**: AWS architectures, from VPC design to event-driven backends.
- **Homelab**: a self-hosted Ubuntu and Docker server with WireGuard VPN, DNS filtering and monitoring.
